# pumping

Pumping Tracker: Breast Milk. An offline breast pumping log for iPhone: a session timer with left and right amounts, today's total against your goal, a next-pump reminder counted from the start or the end of your last session, a freezer stash in use-by order, trends, and PDFs for your lactation consultant or caregiver.

Expo SDK 57, React Native, TypeScript, expo-sqlite, RevenueCat. See CLAUDE.md for how shipping works and NOTES.md for the change log.

```
npm install
npx tsc --noEmit
npm test
npx expo start --ios
```

Website (GitHub Pages, from docs/): https://bkdigitalleads-cmyk.github.io/pumping/
